地图设计思路：

地图尺寸：12 x 10 (比较紧凑的室内)

上方：一个凸起的舞台区域，你的 Boss 可以渲染在这里。

中间：红地毯，两边有沙发，像是一个会客厅。

下方：入口。

C++

碰撞检测 (Collision): 在你的玩家移动逻辑里，你需要判断目标格子的 ID。

Village: 如果 ID 是 1 (树), 3 (水), 5 (墙), 9 (栏)，则 return 禁止移动。

Interior: 如果 ID 是 11 (墙), 13 (沙发), 16 (盆栽)，则禁止移动。

Boss 和 NPC 放置:

Boss: 在渲染 Interior 地图时，你可以手动写死代码，或者解析地图时检测：如果渲染到坐标 (x:5, y:2) (舞台中心)，就在那里额外渲染一个 Boss 的 Sprite。

NPC: 可以在 Village 的花园区域 (x:16, y:11) 放一个园丁 NPC。

渲染层级:

现在的地图是单层的。为了让效果更像口袋妖怪（比如人物可以被房顶遮挡），你可能需要简单的Y轴排序（Y Sorting），或者把“房顶”和“树冠”单独分层渲染在玩家之上。如果不想太复杂，暂时先都画在玩家下面也可以，只是这就没有“这就没有“绕到房子后面”的效果了。
